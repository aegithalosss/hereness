# status/ · 状态提示

小猫下面那行字（中文"待机""敲代码"……，英文 Idle / Coding …）从哪儿来、怎么改成自己喜欢的说法。
**一个 txt = 一种状态提示**，在 Settings → 风格化 → 状态提示 里选一种，或者选"关闭"不显示。

## "默认"是程序自带的，改不了

"默认"那套字写在程序里，这个文件夹里没有它的文件。想要不一样的说法，就照下面复制一份自己改。

## 想换个说法：复制"喵"那份，改一改

1. 复制 `meow.txt`，改个文件名（比如 `test.txt`）；想让英文界面也是自己的说法，就再复制 `meow.en.txt` 改名成 `test.en.txt`。
2. 打开它，先把第一行的 `名字 = 喵呜` 改成你想起的名字（英文那份是 `name = ...`）——这就是下拉里显示的名字。
   没写这一行的话，就用文件名当名字。
3. 想改哪句就改哪句：等号右边是显示的字；用 `|` 隔开就是每次随机挑一句。
   - **只写几句也行：** 没写的、和等号右边留空的，都用"默认"那份的同一句。
   - **只写一种语言也行：** 只写了 `test.txt` 时，英文界面照样显示它的中文；反过来也一样。
   - 等号**左边**的英文名（`idle`、`typing`……）不要改，那是程序认的。
4. 保存（UTF-8，Windows 记事本默认就是），**退出桌宠、重新打开**就生效 —— 不用重装、不用改程序。

例子（`test.txt`）：

```
名字 = 我家的猫
idle = 躺着呢
typing = 在打字
thinking =
```

结果是：待机显示"躺着呢"、敲代码显示"在打字"，别的都跟"默认"一样（`thinking` 留空 = 用"默认"的）。

## 这个文件夹在哪儿

- Windows 版：**exe 旁边的 `status\`**（解压出来和 exe 并排）。
- Mac 版：`~/Library/Application Support/com.aegithalos.hereness/status/`。
- 从源码跑（开发时）：项目里的 `status/`。
- 最省事的找法：设置里"状态提示"那一行下面有个"打开状态提示文件夹"按钮，点它直接打开。
- **文件夹不在、或者里面一个 txt 都没有**：小猫照常工作，下面显示"默认"那套字，不报错、也不弹提示。
  把 `status` 整个改名或拿走，效果一样。

## 别的

- 举手气泡折叠时那行"[名字] **找你**"里的"找你"也在这里改：加一行 `need_you = 找你`（英文 `need_you = needs you!`）。
  没写的自动用"默认"那份的。
- 想删掉自己试的那份：直接删文件，重开就没了（下拉里跟着消失）。选中的那份不在了，就退回"默认"。
- 格式和写法细节在每个 txt 的开头；以 `#` 开头的行是说明，程序不读。
- 字不按字数截：放得下就全显示，放不下才在末尾出省略号。尽量写短一点。
