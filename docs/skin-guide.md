# 皮肤制作指南

## 基础知识（看完就能换！）

右键小猫 > Settings > 风格化
我们默认的两个皮肤分别是Evie （Aegithalos家里的小猫）和雪人（贡献桌宠想法的美少女Denise家的小猫）

**这两个皮肤的具体区别：**Evie的idle状态是一个绑骨动画，小猫的耳朵和尾巴都会动。然后Evie的皮肤有一些特殊的特效。你那边用不上的话可以删掉。

**复制任意一个文件夹**，在skin.json里更改名字的部分就可以开始替换图片制作自己的专属皮肤了。

其余的话只要制作对应名字的图片就可以了。如果懒得做那么多图片可以自由地在设置里选取你觉得合适的图。就算只有一张图也是可以跑通整个桌宠的（就是没有那么多变化了）

"设置详细皮肤"里，有几个可有可无的动作（思考过度、闲着、困了、戳醒、提起），那一行前面有on off开关。关掉的是这一个动作：到了这个动作小猫会直接跳过，也不出声。

## 小猫图片的格式

1. **画**：每张 **400×400、透明背景** PNG，一只猫一个动作（命名按照settings里提供的来，也可以看下方的《文件名字对照表》）我的小猫是按照脚底对齐的，所有动画的旋转中心都在小猫脚这里的位置。(400像素的图片里，200,  325这个位置)
2. **放**：在 `skins` 文件夹里新建一个文件夹（名字随便，中文也行，比如 `小猫3`），把图丢进去。皮肤文件夹在哪，看下面《皮肤放在哪儿》。
   文件名照下面《文件名字对照表》（**文件名就是程序认的名字**，一个字都不能差，大小写倒是随意）；
3. **选**：设置 → 风格化 → **当前皮肤** → 选它 → **立刻换上**。之后加图、改图，点一下设置窗口让它回到前面，小猫就会重新读图；还没变的话，右键退出桌宠、再打开。
4. **缺**：缺的也没关系：程序会照《缺图借用表》借别的图顶上（实在都没有就显示 🐱）。

## 皮肤放在哪儿

一个子文件夹 = 一只皮肤（`evie/`、`xueren/`……）。所有皮肤都在同一个 `skins` 文件夹里：

| 你用的是 | `skins` 文件夹在 |
|---|---|
| Windows 版 | `Hereness.exe` 旁边的 `skins\` |
| Mac 版 | `~/Library/Application Support/com.aegithalos.hereness/skins/` |
| 从源码跑（开发时） | 项目里的 `skins/` |

最省事的找法：设置 → 风格化 → **设置详细皮肤** → **打开这只皮肤的文件夹**，往上一层就是 `skins`。

- 文件夹名字随便起（`雪人`、`小猫3`、`my-cat` 都行），只是别用 `.` 开头（那样不算皮肤）。
- Mac 版每次打开时，只会把缺的整只自带皮肤补回来，已经在的文件夹一个文件都不动，所以改自带皮肤的图不会被盖掉。

> "设置详细皮肤"那一页还能**只换某一行**（比如只有举手想用自己的图）：
> 缺图的行可以从这只皮肤自己的图里挑一张或一个文件夹（里面几张随机挑）顶上，挑完马上换、也会记住。

## 文件名字对照表

一个动作 = 一个固定名字的 png。**文件名就是设置里英文行名的小写，去掉空格**（On it → `onit.png`，Poked → `poked.png`），大小写随意（`Idle.png` 和 `idle.png` 一样）。

| 设置里那一行 | 文件名 | 什么时候出现 | 必须吗 |
|---|---|---|---|
| 待机 / Idle | `idle.png` | 闲着没事（最常看到的那张） | **建议有** |
| 接活 / On it | `onit.png` | agent 接到你的指令 | 可选 |
| 思考 / Thinking | `thinking.png` | 在思考 / 用工具 | 建议有 |
| 思考过度 / Overthinking | `overthinking.png` | 想很久（"对眼"，偶尔出现） | 可选 |
| 读文件 / Reading | `reading.png` | 查资料（读文件、搜网页） | 可选 |
| 工作 / Typing | `typing.png`（或 `typing1.png`、`typing2.png`） | 写代码 / 改文件。编号的几张会轮流播，像在打字 | 建议有 |
| 跑命令 / Running | `running.png` | 跑命令、等结果（躺在沙发上打电动的那张） | 建议有 |
| 举手 / Notify | `notify.png`（或 `notify1/2/3.png`） | **举手**：agent 在等你批准（多张会随机挑） | **建议有** |
| 出错 / Error | `error.png` | 出错 | 可选 |
| 戳戳 / Poked | `poked.png` | 醒着时被戳一下 | 可选 |
| 闲着 / Bored | `bored.png`（或 `bored1/2/3/4.png`） | 闲着久了（Evie 画了四张：看旁边 / 扭头 / 侧身 / 背对你，隔一会儿随机换） | 可选 |
| 困了 / Yawn | `yawn.png` | 困（想睡了） | 可选 |
| 戳醒 / Wake | `wake.png` | 被戳醒 / 来活把睡着的它叫起来 | 可选 |
| 提起 / Grab | `grab.png` | **被拎起来**（按住拖动时） | 可选 |
| 干完活 / Done | `done.png` | 干完活（开心） | 可选 |
| 生气 / Angry | `angry.png` | 举手满 2 分钟没人理，生气一下；连着戳它（3 秒内 10 下） | 可选 |
| 睡着 / Sleep | `sleep.png`（或 `sleep1/2/3….png`） | 睡着（随机挑一张，每 15 分钟换一张；**画几张都行**） | 可选 |

**特效图**是叠在上面那些图上的小东西（loading 圈、汗、屏幕的光），文件名按 **`vfx_行名_叫什么`** 起：`vfx_` 开头，中间是它叠在哪一行的文件名，最后是你给它起的名字。特效图不会出现在整只猫的选图列表里。除了投影，其它特效都要在 `skin.json` 里写明叠在哪几张图上，不然不会出现（见下面《特效》）。

| 特效文件名 | 是什么 |
|---|---|
| `vfx_thinking_loading.png` | 思考时转圈的 loading |
| `vfx_grab_shadow.png` | 被拎起来时的**地面影子**（有这张图就会出现，不用写 `skin.json`） |
| `vfx_error_sweating.png` | 出错时往下滴的汗（Evie） |
| `vfx_running_laptopLight.png` | 跑命令时笔记本屏幕的光（Evie） |
| `vfx_running_gameboyLight.png` | 跑命令时游戏机屏幕的光（Evie） |

## 一个动作想放好几张（随机）

**两种写法都认**：

**① 用编号**：`sleep1.png`、`sleep2.png`、`sleep3.png`……（最省事，推荐）

**② 建一个和动作同名的文件夹**，里面放几张，里面的图名字随意：

```
sleep/     ← 文件夹名就是文件名对照表里的名字（sleep）
  a.png
  b.png
```

- 张数不限。进这个动作时**随机挑一张**，而且**不和上一张重复**；
- 例外：工作（`typing`）的几张会**按顺序轮流播**，像在打字；
- 同一个动作既有文件夹又有 png 时，先用文件夹；文件夹里没有 png 就当没有这个文件夹。

## 缺图借用表（不画也能跑）

没画的动作会照这张表一路借下去（→ 表示"借它"）：

```
接活 onit → thinking → idle
思考 thinking → idle
读文件 reading → typing → idle
工作 typing → idle
跑命令 running → typing → idle
举手 notify → idle
出错 error → thinking → idle
生气 angry → error → thinking → idle
戳戳 poked → idle
戳醒 wake → poked → idle
闲着 bored → idle
睡着 sleep → idle
干完活 done → idle
（`overthinking`、`yawn`、`grab` 和特效图没有借用：缺了就跳过那一小段）
```


**只画 3 张就想跑起来**：`idle.png`（待机）+ `notify.png`（举手）+ `running.png`（等结果）——这三张是日常最常看到的。

## 声音

- 声音放在这只皮肤自己的 `sounds/` 文件夹里（里面可以再分子文件夹），支持 mp3、wav、ogg。复制皮肤，声音一起带走。
- **声音的文件名随便起**，程序不按名字猜；哪个动作响哪个，看设置里"设置详细皮肤"右边那列声音，也可以在下拉里自由选。选文件夹的话，每次随机挑一个。
- 进入那个动作时响一次，播完就停，不循环。
- 想让这只皮肤自带一套声音，就在 `skin.json` 里写（行名 → `sounds/` 里的文件或文件夹；文件夹末尾写 `/`）：

```json
"sounds": {
  "prompt": "Mia.mp3",
  "notify": "Notif/",
  "lifted": "complain/",
  "dropped": "complain/"
}
```

- 这里的行名是程序内部的名字，和图片文件名不完全一样：`idle` 待机、`prompt` 接活、`thinking` 思考、`crosseye` 思考过度、`reading` 读文件、`typing` 工作、`bash` 跑命令、`notify` 举手、`error` 出错、`poke` 戳戳、`look` 闲着、`yawn` 困了、`wake` 戳醒、`lifted` 提起、`done` 干完活、`angry` 生气、`sleep` 睡着、`dropped` 放下（只有声音、没有图）。
- 用户在设置里选的盖过 `skin.json` 写的；每行的 × 是"这一行不响"，最底下"恢复默认"回到 `skin.json` 写的。写的文件不在了，那一行不响，面板上显示 `(missing)`。

## 更详细的图片规格

| 项目 | 要求 |
|---|---|
| 尺寸 | **400 × 400**，每张都要一样大 |
| 格式 | **PNG，透明背景**（不要白底，不要 JPG） |
| 位置 | 想让猫站在画布哪个高度，就画在哪儿——**程序不改图，画在哪就显示在哪**。绕哪一点转（支点）写在皮肤文件夹里的 `skin.json`（见《skin.json 里的数字》） |
| 大小 | 猫在画布里的**大小也尽量一致**（不同动作之间别忽大忽小） |
| 透明边 | 四个角要透明；边缘别留白边（自检工具会提示"边缘有……很亮的像素"） |
| 留白 | 建议画面四周留出 20% 的空白。画得太满，动起来容易被切掉。画得高的图，可以跑一下自检看看（见《自己检查》） |

**支点为什么重要**：程序不改图，图在画布上画在哪就显示在哪；歪头、左右摇、被戳时拉高，都是**绕支点**转的。支点统一在 **(200, 325)** ——同一只猫的各张图都按这个点画，换动作时它才不会"绕着奇怪的地方转"。各张图画得高低不一，换动作时还是会上下跳一点，那是正常的（位置由你画在哪决定）。

## skin.json 里的数字

皮肤文件夹里可以放一个 `skin.json`，把程序要用的**坐标**、**显示名**和**作者**写在这儿。**程序只照读：不会替你改图，也不会自己发明坐标。**
不写就用默认值（= 两只自带猫现在的数，可以直接看 `skins/evie/skin.json`）。所有坐标都是**原图画布上的像素坐标**（画布 400×400，就往 0–399 里写）。

```json
{
  "name": { "zh": "Evie", "en": "Evie" },
  "credits": ["Art Direction & Editing: Aegithalos", "AI Image Generation: ChatGPT"],
  "pivot": [200, 325],
  "grab": [200, 90],
  "shadow": { "pivot": [200, 332] },
  "overlays": {
    "vfx_thinking_loading": { "on": ["thinking", "overthinking"], "pivot": [196.1, 85.81] }
  },
  "rig": {
    "idle": {
      "pivots": {
        "Tail1": [203.5, 251], "Tail2": [186, 301.5], "Tail3": [137.3, 307], "Tail4": [97, 289],
        "earL": [230.7, 121.3], "earR": [176, 116.7]
      }
    }
  }
}
```

| 键 | 是什么 | 怎么量 / 怎么写 | 不写的话 |
|---|---|---|---|
| `name` | **设置里显示的名字**。写一句话（`"小猫3"`）中英文都用它；也可以分语言（`{"zh":"雪人","en":"Xueren"}`） | 直接写字符串。复制别人的皮肤时记得改，不然下拉里两只同名（设置会补文件夹名区分，比如"雪人（cat3）"） | 显示文件夹名 |
| `credits` | **作者署名**，一行一条，原样显示在设置里 | 写成一组文字。复制别人的皮肤时改成你自己 | 不显示 |
| `pivot` | **整只猫的支点**：歪头、左右摇、被戳拉高、换动作弹一下，都绕这一点转 | 在 Photoshop 里把标尺拖到你想让它转的那一点，读坐标。两只自带猫都是 **(200, 325)** | 用 (200, 325) |
| `grab` | **被拎起来**时手抓的那一点（鼠标会钉在这儿，晃动也绕它） | 在 `grab.png` 上量"拎的那个部位"（Evie = 脑门，**(200, 90)**） | 用 (200, 90) |
| `shadow.pivot` | **地面投影（`vfx_grab_shadow.png`）自己的缩放中心** | 在 `vfx_grab_shadow.png` 上量那块暗色的中心（见《特效》） | 用 (200, 332) |
| `overlays` | **特效**：每个特效叠在哪、怎么动 | 见《特效》 | 没有特效（投影除外） |
| `rig.idle.pivots` | **分层待机部件各自的旋转点**——会转的只有尾巴四节和两只耳朵 | 见《会动的待机（分层）》。这里的键名大小写要照写：`Tail1`、`earL` | 那几个部件会绕图片中心转（看着会怪） |
| `sounds` | **这只皮肤自带的声音** | 见《声音》 | 不响 |

**例外只有三种：** 被拎起来的 `grab.png`（用自己的抓取点）、特效（`vfx_thinking_loading`、`vfx_running_…`，用它们自己的中心）、地面投影（`vfx_grab_shadow.png`，用 `shadow.pivot`）。**其它所有图都按 `pivot`。**

`skin.json` 改完，点一下设置窗口让它回到前面，或者重开一次桌宠，就生效，不用重新编译程序。

## 特效

特效图的名字照 **`vfx_行名_叫什么`** 起（见《文件名字对照表》）。特效图**画在哪，动画就从哪开始**，程序不改图。复制别人的皮肤时，这些数跟着 `skin.json` 一起过来；位置一样就不用改。

### loading 圈和其它叠在图上的特效

1. 画一张 400×400 透明 PNG，比如转的那个圈 `vfx_thinking_loading.png`；
2. 在 `skin.json` 的 `overlays` 里给它写一项：`on`（叠在哪几张图上）、`motion`（怎么动），再加几个可选的数。

```json
"overlays": {
  "vfx_thinking_loading": { "on": ["thinking", "overthinking"], "pivot": [196.1, 85.81] }
}
```

- **只有 `skin.json` 里写了这一项，特效才会叠上去**；光有图不会自动出现。
- **`on` 里写这只皮肤自己的图的文件名**（不带 `.png`）。思考图是一张 `thinking.png` 就写 `"thinking"`；画成了 `thinking1.png`、`thinking2.png` 或放进了文件夹，就把每张的名字都写上，不然那几张上不会出现。
- `pivot` 是特效自己的中心（比如 loading 圈绕哪一点转）。**可以不写**：不写就按这张图自己的中心。圈画在画布中间（(200, 200) 附近）时不用写；画在别处就得写，不然圈会绕图中心"跑圈"。
- 同一张图最多同时叠 3 个特效。特效只在 `on` 写的那几张图显示时出现；换状态、换皮肤时马上收掉；小猫窗口看不见时（被挡住、最小化）动画先停。

`motion` 有四种，不写就是 `spin`（转圈）。距离都按**画布像素**写（和 `pivot` 一样量），程序按小猫实际大小换算；想让汗从别处滴，把汗画在别处就行，数字不用改。

| motion | 样子 | 能写的数（不写就用默认） |
|---|---|---|
| `spin` | 绕 `pivot` 转圈（loading 圈） | `ms` 转一圈多久，默认 1000；`steps` 一圈跳几格，默认 9，写 0 = 平滑地转 |
| `drip` | 从画的位置往下落、一边落一边淡掉，停一会儿再从原处落 | `ms` 落一次多久，默认 1400；`gap` 落完停多久，默认 2600；`distance` 往下落多少，默认 36；`curve` 落的时候往右（正）/左（负）弯多少，默认 0（直着落） |
| `pulse` | 一明一暗，像呼吸灯 | `ms` 一明一暗一共多久，默认 2800；`min` 最暗时还剩多少（0～1），默认 0.35 |
| `flicker` | 亮暗错开地闪，像打游戏的屏幕 | `ms` 一轮多久，默认 1300；`min` 最暗时还剩多少，默认 0.2；`colors` 染色，一组颜色轮着换（比如 `["#ffb3b3", "#b3c8ff"]`），不写就是图本来的颜色 |

`colors` 其实四种都能写：写了就把图当模子、填成这些颜色（所以要染色的特效图最好画成白色）。只有 `flicker` 会轮着换颜色，其它的只用第一种。写了认不出的 `motion`，特效就静止显示。

Evie 的写法（时间单位都是毫秒）：

```json
"vfx_error_sweating":       { "on": ["error"],   "motion": "drip",    "ms": 1400, "gap": 2600, "distance": 36, "curve": 6 },
"vfx_running_laptopLight":  { "on": ["running"], "motion": "pulse",   "ms": 2800, "min": 0.35 },
"vfx_running_gameboyLight": { "on": ["running"], "motion": "flicker", "ms": 1300, "min": 0.2, "colors": ["#ffb3b3", "#b3c8ff"] }
```

### 地面投影（被拎起来时的影子）

1. 画一张 400×400 透明 PNG，叫 `vfx_grab_shadow.png`（和 `grab.png` 摆在**同一套画布坐标**里）。有这张图，拎起来时就会出现，不用写 `overlays`；
2. 想改它的缩放中心，在 `skin.json` 里加一行：

```json
"shadow": { "pivot": [200, 332] }
```

- 这是**投影自己的缩放中心**：拎起来晃的时候，投影一边缩小一边反向转回来，缩小的中心必须落在投影自己身上——不落在它身上，缩小时会往一边偏，看着像抖。
- **拎起来时程序不挪影子**：影子显示在哪，只看 `vfx_grab_shadow.png` 本身；要挪就在原图里挪。
- 在 Photoshop 里量 `vfx_grab_shadow.png` 里那块暗色的中心。**不写就用默认 (200, 332)**（= 两只自带猫现在的数）。

## 自己检查（要从源码跑）

下面两个工具都只读，不改任何原图，要在项目文件夹里用 Node 跑。

**检查图**：

```
node tools/pivot-check-sheet.cjs 你的文件夹名
```

打开 `AgentOutputs/pivot-check-你的文件夹名.png`（不写文件夹名就每只皮肤各画一张）。每格一张图，格子左上角的数字对应命令行里打出来的名字清单：

| 十字 | 是什么 |
|---|---|
| 红十字 | 支点 `pivot`（满格横竖两条） |
| 蓝十字 | `grab.png` 上的抓取点 |
| 橙十字 | 尾巴关节 / 耳根（`rig.idle.pivots`） |
| 绿十字 | loading 圈的中心（`overlays.<名字>.pivot`）——画在圈自己那张图上，也画在它叠的那几张图上 |
| 紫十字 | 投影的中心（`shadow.pivot`）——画在 `vfx_grab_shadow.png` 上 |

命令行还会打印**从图里量出来的参考值**（投影 = 那块暗色的加权重心；loading 圈 = 圆拟合量出来的圆心，带半径和误差）。那只是给你对照的：**程序绝不会自动采用**。觉得对，就把数抄进 `skin.json`，再跑一次检查图核对。

**自检**：

```
node tools/build-skin.cjs 你的文件夹名
```

它会报：画布尺寸对不对、支点/抓取点/投影中心读到没、特效叠对了没、有没有认不出的文件名、有没有白边，还有哪张图动起来会被切掉。

## 会动的待机（分层，最难）

Evie 的待机是会动的：尾巴一节一节甩、耳朵抖、眨眼——那是把待机拆成 **12 个部件**，放在皮肤文件夹的 `idle_rig/` 里：

```
idle_rig/ 里的文件（文件名就是部件名，大小写随意）：
  body      整个身体（不动的底）
  face      脸
  earL      左耳          earR      右耳
  Tail1     尾巴第 1 节（最靠身体）  Tail2     第 2 节   Tail3     第 3 节   Tail4     第 4 节（最靠尖）
  EyelidTL  左上眼皮      EyelidTR  右上眼皮   EyelidBL  左下眼皮   EyelidBR  右下眼皮
```

- **不做也能跑**：待机就显示整张 `idle.png`（大多数人这样就好）；`body`、`face`、两只耳朵、四节尾巴缺一张，也会退回整张 `idle.png`。
- 想做的话：部件要**互相对齐**（每张都是 400×400、画在同一套坐标上）。最省事是直接替换 `evie/idle_rig/` 里的图，每张的位置和旋转中心和原图保持一致。
- 自己画的话，尾巴关节和耳根的坐标要在 Photoshop 里量，写进 `skin.json` 的 `rig.idle.pivots`（键名照上面写，大小写也一样）：`Tail1` 是尾巴根，`Tail2/3/4` 是它和上一节的接缝，`earL/earR` 是耳根。量完用检查图看一眼橙十字。**这一块比较费工，建议先做基础的，以后有空再加。**

## 想跟着程序一起发布的皮肤

自己用的话，放进《皮肤放在哪儿》说的 `skins` 文件夹就行。想在源码里加一只、打包时一起带上：

1. 在项目的 `skins/` 里新建 `skins/<皮肤名>/`，把图放进去（文件名照《文件名字对照表》），`skin.json` 里写好 `name` 和 `credits`；
2. 把文件夹名加一行进 `tools/release-skins.txt`，打包时才会带上它。

## 常见问题

| 现象 | 多半是 |
|---|---|
| 换上了但没变化 | 文件名不对（多了空格、拼错）／不是 PNG／不是透明背景 |
| 某几个动作还是原来的样子 | 那些名字的图没放（照《缺图借用表》借到别的图了） |
| 猫一跳一跳 | 各张图画得高低不一（程序不改图，位置就是你画的位置，见《更详细的图片规格》） |
| 转起来怪怪的 / 绕错地方转 | `skin.json` 里的 `pivot` 不对或没写（见《skin.json 里的数字》），可以跑检查图看一眼 |
| 动起来头或脚被切掉 | 画得太满了，四周留 20% 空白；跑 `node tools/build-skin.cjs <文件夹名>` 看哪张会被切 |
| 思考时没有 loading 圈 | ① 图不叫 `vfx_thinking_loading.png`；② `skin.json` 的 `overlays` 没写这一项；③ `on` 里填的不是这只皮肤自己思考图的文件名——见《特效》 |
| loading 圈不原地转、像在跑圈 | `overlays.vfx_thinking_loading.pivot` 没写或写错（不写就按那张图自己的中心转），跑检查图看绿十字 |
| 拎起来时投影缩小时往一边偏 / 像在抖 | `skin.json` 的 `shadow.pivot` 不对或没写（不写就用默认 (200, 332)），跑检查图看紫十字 |
| 尾巴不甩了 | `idle_rig/` 里缺了部件，或 `skin.json` 里 `rig.idle.pivots` 的键名写错（要照写 `Tail1`、`earL`）；跑 `node tools/build-skin.cjs <文件夹名>` 看它报什么 |
| 边缘有白边 | 去背景没去干净（自检工具会提示"边缘有……很亮的像素"） |
| 加了图没生效 | 点一下设置窗口让它回到前面；还不行就**重开一次桌宠**（右键 → 退出，再打开） |
| 设置里的下拉看不到新皮肤 | 文件夹放错地方了（见《皮肤放在哪儿》）；或者名字以 `.` 开头（那不算皮肤） |
| 下拉里两只皮肤名字一样 | 复制别人的皮肤时 `skin.json` 里的 `name` 没改（设置里会补文件夹名区分，比如"雪人（cat3）"） |
